🕹️ Tic-Tac-Toe Game
Welcome to a fun and simple web-based Tic-Tac-Toe Game built using modern web technologies! Play against a friend locally and enjoy the classic game of Xs and Os with an intuitive and responsive user interface.

🌐 Live Demo: https://hilarious-crumble-824c55.netlify.app/

📌 Features
🎮 Two-player local game (Player X vs Player O)

🧠 Intelligent game logic with win/draw detection

✨ Clean and minimalistic UI

📱 Fully responsive — works on all screen sizes

🔁 Reset functionality to restart the game

🛠️ Tech Stack
HTML5

CSS3

JavaScript
